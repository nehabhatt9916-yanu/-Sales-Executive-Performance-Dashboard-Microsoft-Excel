📊 Sales Executive Performance Dashboard | Microsoft Excel


**🚀 Project Overview**

This project is an interactive Sales Executive Performance Dashboard developed in Microsoft Excel to analyze and monitor the performance of sales executives across multiple regions in India.

The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPIs, and region-wise analysis, enabling management to evaluate sales performance and make informed decisions.

**🎯 Project Objective**

The primary objectives of this project are to:

Track sales executives' performance across different regions.
Compare actual sales against targets.
Identify top and low-performing executives.
Analyze regional sales trends.
Support data-driven business decisions through interactive dashboards.

The project analyzes sales performance across multiple Indian cities including Bangalore, Chennai, Delhi, Hyderabad, Jaipur, Kolkata, Mumbai, Nagpur, Patna, Pune, Ranchi, and Surat.
